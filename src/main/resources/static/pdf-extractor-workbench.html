Workflow

      

        
Use this page for the permanent PDF path:

        
PDF -> backend extractor -> JSON -> viewer / pre-git

        
The extractor engine uses profile-based geometry, crops content-only frames, normalizes them to legacy canvas sizes, and returns stable JSON output.

        
For viewer usage, take the downloaded JSON and load it in your external Viewer.html. For question bank migration, use Pre-Git JSON.
