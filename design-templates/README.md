# Design Templates

This directory stores gold-copy UI templates for the exam platform.

These files are reference snapshots, not runtime files. The live application still uses files from `src/main/resources/static`.

## Contents

- `response-sheet/candidate-response-sheet-template.html` - candidate response sheet web and print/PDF layout reference.
- `exam-ui/candidate-exam-ui-template.html` - candidate exam window UI reference.

When a UI version becomes stable, copy the live file here with a clear filename before making experimental changes.
